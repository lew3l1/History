# Истории для души

Семейная библиотека выпусков канала RuTube «Истории из жизни: Влад — ТАК НЕ БЫВАЕТ».

## Возможности первой версии

- Адаптивная главная страница, крупная типографика и большие кнопки.
- Каталог роликов с поиском.
- Встроенный плеер RuTube: воспроизведение, пауза, стоп, громкость, перемотка на 15/30 секунд и переключение выпусков.
- Локальное сохранение позиции просмотра и список начатых историй.
- Облачная история на Supabase для входа по почте и Google.
- PWA-манифест для добавления сайта на главный экран телефона.
- GitHub Actions обновляет каталог и публикует сайт ежедневно.

## Локальный запуск

1. Установить Node.js 22 или новее.
2. Выполнить npm install.
3. Выполнить npm run sync:rutube для загрузки каталога.
4. Выполнить npm run dev и открыть локальный адрес Vite.

Без настроенного Supabase сайт работает локально: место просмотра хранится в браузере текущего устройства.

## Подключение аккаунтов и синхронизации

1. Создать проект Supabase.
2. Выполнить содержимое файла supabase/schema.sql в разделе SQL Editor.
3. В Supabase включить Google в Authentication -> Sign In / Providers.
4. В Authentication -> URL Configuration добавить localhost для разработки и опубликованный адрес сайта в Redirect URLs. После публикации указать URL сайта как Site URL.
5. В GitHub Repository -> Settings -> Secrets and variables -> Actions добавить Repository secrets VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY.
6. Для локальной разработки создать файл .env.local с теми же переменными.

Используется только публичный anon/publishable ключ клиента. Никогда не добавляйте service_role key в клиентское приложение или GitHub Pages.

## Публикация

В репозитории открыть Settings -> Pages и выбрать GitHub Actions в поле Source. После публикации адрес проекта: https://lew3l1.github.io/History/

Для Google OAuth добавьте фактический адрес сайта в список разрешённых redirect URLs Supabase. Service role key не требуется.

## Каталог RuTube

Скрипт scripts/sync-rutube.mjs читает публичный список видео канала через JSON endpoint, используемый extractor-проектом yt-dlp. Это не официальный публичный API с гарантией стабильности. Если RuTube изменит endpoint или ограничит запросы, опубликованный сайт продолжит работать с последним успешно сохранённым public/data/videos.json, а обновление каталога потребует исправления скрипта.

Видеопотоки не копируются и не хранятся в этом репозитории: ролики проигрываются во встроенном плеере RuTube.
